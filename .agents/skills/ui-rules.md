# UI Rules for AI (PHMX Framework)

Saat membuat atau memodifikasi antarmuka pengguna (UI) untuk proyek ini, Anda **DIWAJIBKAN** untuk mematuhi aturan-aturan berikut demi menjaga konsistensi dan estetika proyek:

1. **Gunakan Style yang Sudah Ada (Consistent Styling)**
   - Selalu gunakan komponen dan kelas CSS bawaan yang sudah ada di proyek (seperti standar Bootstrap yang selama ini digunakan).
   - Jangan pernah menambahkan styling *inline* (`style="..."`) atau membuat file CSS khusus baru secara sembarangan kecuali benar-benar diperlukan.
   - Tiru struktur HTML, tata letak (*layout*), dan komposisi warna dari halaman-halaman yang sudah ada sebelumnya.

2. **Pendekatan Minimalis (Minimalist Design)**
   - Jaga agar desain tetap bersih, rapi, dan tidak berdesakan.
   - Hindari elemen dekoratif berlebihan (terlalu banyak bayangan/shadow, warna-warni berlebih, animasi berlebihan, dsb).
   - Fokuslah pada utilitas dan fungsionalitas: fungsionalitas harus menjadi pusat perhatian pengguna. Gunakan ruang kosong (*whitespace*/padding/margin) secara optimal untuk mengarahkan pandangan.

3. **Batasi Penggunaan Ikon dan Hapus Emoji**
   - **JANGAN** menggunakan emoji (seperti 🚀, 🛡️, dsb) pada UI atau pesan teks ke pengguna, kecuali diminta secara spesifik.
   - Gunakan ikon dengan sangat hemat. Hanya gunakan ikon pada area di mana ia benar-benar memberikan nilai tambah secara fungsional (misal: tombol aksi Hapus/Edit).
   - Lebih baik mengandalkan tipografi yang jelas (tebal/tipis, besar/kecil huruf) dan penyusunan teks yang baik daripada memaksakan bantuan visual berupa ikon.
